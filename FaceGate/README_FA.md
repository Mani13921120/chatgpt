# FaceGate 0.5.0 — ویندوز ۱۰/۱۱

راهنمای قفل پوشه، PIN و بازیابی: [FOLDER_LOCK_FA.md](FOLDER_LOCK_FA.md)

راهنمای فهرست Start/Store، نگهبان مستقل و Task Manager: [APPS_GUARDIAN_FA.md](APPS_GUARDIAN_FA.md)

برای نصب، Python 3.13 x64 را نصب و `install_and_run.bat` را اجرا کنید. این فایل وابستگی‌ها را در `.venv` همان پوشه نصب و مدل‌های YuNet و SFace را دریافت می‌کند؛ اینترنت لازم است و نصب اول ممکن است چند دقیقه طول بکشد. خطاهای نصب در `install_log.txt` ذخیره می‌شوند. اجراهای بعدی از `RUN_FACEGATE.bat` هستند. بستهٔ ZIP شامل سورس است؛ EXE قبلی به‌صورت خودکار به‌روز نمی‌شود.

برای شروع، رمز یا PIN مدیریت را تنظیم کنید، چهره را ثبت کنید و رمز پشتیبان برنامه‌ها را تعیین کنید. برنامه‌ها را از فهرست ویندوز یا انتخاب EXE اضافه کنید. نگهبان مستقل پس از بستن رابط ادامه می‌دهد؛ وضعیت و دکمهٔ توقف آن داخل رابط است. هنگام ارتقا ابتدا نگهبان نسخهٔ قبلی را با رمز/PIN متوقف و رابط را کامل ببندید.

اطلاعات کاربر در `%LOCALAPPDATA%\FaceGate` می‌ماند. پوشه‌های ثبت‌شده بعد از ارتقا باید «قفل مجدد» شوند. داده‌های بازیابی را حذف نکنید و قبل از محافظت، برنامه‌های استفاده‌کننده از فایل‌ها را ببندید.

تشخیص چهرهٔ وب‌کم با Windows Hello یا Face ID یکسان نیست؛ آستانهٔ تطبیق و نور باید روی دستگاه واقعی بررسی شوند. آزمون خودکار از دوربین شبیه‌سازی‌شده استفاده می‌کند. برای ساخت EXE می‌توان از `build_exe.bat` استفاده کرد؛ ساخت EXE این انتشار آزمایش نشده است.
