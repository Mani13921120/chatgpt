# FaceGate — قفل پوشه (نسخهٔ آزمایشی)

[دانلود مستقیم آخرین بستهٔ ZIP](https://github.com/Mani13921120/chatgpt/raw/refs/heads/main/FaceGate_FolderLock_Experimental.zip)

- پوشهٔ تستی «New folder» ساخته نمی‌شود؛ فقط پوشهٔ موجودی که انتخاب می‌کنید محافظت می‌شود.
- «حذف پوشه از قفل» پس از PIN صحیح فایل‌ها و مجوزها را برمی‌گرداند و پوشه را از فهرست حذف می‌کند؛ خود فایل‌ها حذف نمی‌شوند.
- «فعال‌سازی دابل‌کلیک Explorer» فرمان بازکردن پوشهٔ قفل‌شده را به FaceGate می‌فرستد: بررسی چهره تا ۳ ثانیه، سپس بازکردن در صورت موفقیت یا انتخاب تلاش مجدد / PIN / انصراف در صورت شکست.
- اجرای هم‌زمان چند نسخه جلوگیری می‌شود؛ درخواست Explorer به همان برنامه‌ای می‌رسد که قفل‌ها را نگه داشته است.

[راهنمای اجرا، بازگردانی Explorer و محدودیت‌ها](FaceGate/FOLDER_LOCK_FA.md)

اتصال Shell Open تمام عملیات فایل‌سیستم را رهگیری نمی‌کند: کپی، تغییر نام، نوار آدرس و CMD الزاماً دوربین را فعال نمی‌کنند. پوشش تضمینی همهٔ این عملیات به درایور نیاز دارد.

۳۱ آزمون در Linux موفق و ۶ آزمون Windows/NTFS اجرا نشده‌اند. دوربین و Explorer واقعی در این محیط آزمایش نشده‌اند. ابتدا روی دادهٔ آزمایشی خودتان بررسی کنید. این بسته سورس است و EXE ساخته نشده است.
