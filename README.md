# FaceGate — قفل پوشه (نسخهٔ آزمایشی)

[دانلود فایل ZIP](https://github.com/Mani13921120/chatgpt/raw/refs/heads/main/FaceGate_FolderLock_Experimental.zip)

کد منبع در پوشهٔ `FaceGate` است. راهنمای تغییرات و تست ویندوز: [FOLDER_LOCK_FA.md](FaceGate/FOLDER_LOCK_FA.md).

قفل پوشه به Windows و NTFS نیاز دارد. چهار آزمون منطق و رمزگذاری گذشتند؛ چهار آزمون عملی Windows در محیط Linux اجرا نشده‌اند. ابتدا روی پوشهٔ آزمایشی تست کنید. فایل EXE ساخته نشده است.

قفل مجوز پوشه بعد از خروج باقی می‌ماند؛ محدودیت‌های مبتنی بر handle تنها هنگام اجرای برنامه فعال‌اند. تضمین مطلق در برابر مدیر سیستم یا توقف اجباری برنامه وجود ندارد.
