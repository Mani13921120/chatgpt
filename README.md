# FaceGate — نسخهٔ آزمایشی

[دانلود بستهٔ برنامه](https://github.com/Mani13921120/chatgpt/raw/refs/heads/main/FaceGate_FolderLock_Experimental.zip)

[دانلود ابزار رفع مشکل تب جدید Explorer](https://github.com/Mani13921120/chatgpt/raw/refs/heads/main/FaceGate_Explorer_Repair.zip)

برای ترمیم: ZIP ترمیم را استخراج کنید، RESTORE_EXPLORER.bat را اجرا کنید و پنجره‌های Explorer را ببندید و دوباره باز کنید. ابزار به پایتون یا دسترسی مدیر نیاز ندارد و فقط پیش‌فرض ایجادشده توسط FaceGate را بازمی‌گرداند.

نسخهٔ جدید دیگر فرمان پیش‌فرض دابل‌کلیک پوشه‌ها را عوض نمی‌کند. ناوبری عادی در اختیار خود Explorer می‌ماند. FaceGate از گزینهٔ راست‌کلیک یا داخل برنامه استفاده می‌شود. اتصال سراسری نسخهٔ قبلی در اجرای نسخهٔ جدید نیز بازگردانده می‌شود.

پوشهٔ خالی قابل قفل است. حذف از قفل با PIN، فایل‌ها را حفظ می‌کند. بررسی چهره تا ۳ ثانیه با تلاش مجدد و PIN موجود است. ساخت پوشهٔ تستی خودکار وجود ندارد.

[راهنمای کامل](FaceGate/FOLDER_LOCK_FA.md)

۳۶ آزمون موفق و ۶ آزمون مخصوص Windows/NTFS اجرا نشده‌اند. Explorer، رجیستری و دوربین واقعی ویندوز در این محیط Linux آزمایش نشده‌اند. EXE ساخته نشده است.
